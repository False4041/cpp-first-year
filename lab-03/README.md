# Лабораторная работа 3

Тема: создание простых классов, геттеры и сеттеры. Класс `Coin`, вариант 2 в таблице задания.

[Программа](main.cpp) хранит номинал и количество монет в закрытых полях класса. Конструкторы создают пустой объект, объект с заданными значениями и копию другого объекта. Сеттеры принимают неотрицательные значения, `getTotal()` вычисляет общую сумму, а `getInfo()` формирует строку с информацией. Деструктор выводит сообщение об уничтожении объекта.

В `main` создаются три объекта, демонстрируются чтение полей, расчёт суммы и копирование. Вызов `setCount(-5)` отклоняется: количество остаётся равным 10. Ввод с клавиатуры не требуется.

Скомпилируйте `main.cpp` и запустите программу по инструкции в [общем README](../README.md#как-запустить). Числовые поля имеют тип `int`; проверка переполнения произведения не предусмотрена.
