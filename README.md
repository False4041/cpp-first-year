## Как запустить

Каждый `main.cpp` — самостоятельная программа. Для неё нужен отдельный исполняемый файл; объединять все исходники в один проект с общей точкой входа не нужно.

Пример с GCC / MinGW из корня репозитория:

```sh
cd lab-01/task-01
g++ -std=c++17 main.cpp -o main.exe
./main.exe
```

Для Visual C++ откройте Developer PowerShell for VS или Developer Command Prompt и перейдите в папку нужного задания:

```powershell
cl /nologo /std:c++17 /EHsc /utf-8 main.cpp /Fe:main.exe
.\main.exe
```

В Visual Studio также можно создать консольный проект и добавить в него **один** `main.cpp`. Для первой лабораторной задайте рабочий каталог программы равным папке задания: входные файлы лежат рядом с исходником. Программы создают или перезаписывают свои выходные файлы в текущем рабочем каталоге.

Во второй лабораторной вводятся длина вектора и его элементы. В пятой программе вводится масса в килограммах. Остальные программы используют приложенные файлы или данные внутри кода.

## Восстановление исходников

Код перенесён со скриншотов из отчётов «Лаба 1.docx» — «Лаба 5.docx». Изображения кода сохранены в `source-screenshots` внутри каждой лабораторной для сверки. Авторские алгоритмы и особенности их поведения сохранены.

При переносе изменено оформление отступов; пути `../../имя_файла` заменены на `имя_файла`, чтобы запускать задания из собственных папок. В первой лабораторной у заданий 5, 8, 9 и 10 восстановлен обрезанный конец `main`, у задания 9 — также заголовки и объявление массива, у задания 10 — заголовки. Эти места отмечены комментариями. В задании 1 лабораторной 2 добавлен явный `#include <functional>` для `std::greater<int>`.

Входные данные, различимые в отчётах, перенесены в текстовые файлы. Для заданий 2–4 первой лабораторной добавлены небольшие демонстрационные данные, поскольку исходное содержимое этих файлов в отчёте не показано.

Все 15 исходников собраны в Visual C++ 2022 в режиме C++17 и проверены на демонстрационных данных. Условия и ограничения исходных решений описаны в README лабораторных; это учебные программы, без полной проверки произвольного ввода.
