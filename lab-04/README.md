# Лабораторная работа 4

Тема: динамический массив целых чисел с конструкторами, деструктором и основными операциями. Класс `IntVector`, вариант 2.

[Программа](main.cpp) управляет массивом через указатель `int*` и размер. Конструктор без параметров создаёт пустой массив, конструктор с размером заполняет его нулями, деструктор освобождает память через `delete[]`.

Метод `pushFront()` выделяет новый массив и добавляет элемент в начало, `popFront()` сдвигает элементы влево и уменьшает размер. Методы `getSize()` и `print()` возвращают размер и выводят элементы.

Демонстрация создаёт массив `30 20 10`, удаляет первый элемент и получает `20 10`. Второй массив содержит три нуля. Ввод с клавиатуры не требуется; команды сборки — в [общем README](../README.md#как-запустить).

В исходном решении `popFront()` уменьшает логический размер без перевыделения памяти. Конструктор копирования и оператор присваивания не определены: копировать объекты `IntVector` в таком виде нельзя, поскольку копия будет разделять указатель и повторно освобождать ту же память. Демонстрационный `main` объекты не копирует.
