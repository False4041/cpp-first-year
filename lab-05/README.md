# Лабораторная работа 5

Тема: перегрузка операторов и дружественные функции. Класс `Mass`, вариант 12.

[Программа](main.cpp) хранит массу в килограммах в поле `double`. Конструкторы создают пустой объект, объект с заданной массой и копию другого объекта; геттер и сеттер читают и изменяют массу. Метод `toGrams()` переводит килограммы в граммы.

Для объектов перегружены сложение, вычитание и сравнения `==`, `!=`; для массы и числа — умножение и деление. Деление на ноль выбрасывает `runtime_error`. Дружественные операторы `<<` и `>>` обеспечивают вывод и ввод массы.

В `main` демонстрируются значения 2 и 3 кг, операции над ними и копирование. Затем нужно ввести ещё одну массу: например, для `1.25` программа выведет `d = 1.25 kg` и `d (grams) = 1250`. Команды сборки — в [общем README](../README.md#как-запустить).

Исходный класс допускает отрицательные значения и сравнивает `double` напрямую. Обработка ошибок ввода и перехват исключения деления на ноль в демонстрационном `main` не предусмотрены.
