# Лабораторная работа 2

Тема: векторы и итераторы. В отчёте для обоих заданий выбран вариант 2.

## Задание 1

[Программа](task-01/main.cpp) считывает `n` целых чисел в `std::vector`, сортирует их по убыванию и заменяет элементы с индексами 0, 2, 4… на их порядковые номера 1, 3, 5…. Для сортировки используются итераторы `begin()` и `end()`.

Пример ввода:

```text
6
10 20 30 40 50 60
```

Результат: `1 50 3 30 5 10`.

## Задание 2

[Программа](task-02/main.cpp) выделяет первую половину и среднюю треть вектора функцией `part`. Затем вычисляет среднее каждой части и считает все пары разных элементов внутри каждой части, сумма которых больше порога `max17`. Порог ищется по элементам исходного вектора, кратным 17; пары не обязаны быть соседними.

Пример ввода:

```text
6
10 20 30 40 51 60
```

Результат: средние `20` и `35`, количество пар — `0` и `1`.

Исходная реализация начинает поиск `max17` с нуля. Поэтому при отсутствии положительных кратных 17 порог остаётся равным нулю, в том числе если есть только отрицательные кратные. Для вычисления обоих средних нужно `n >= 2`; границы частей определяются целочисленным делением. Предполагается корректный целочисленный ввод.

## Запуск

Каждый `main.cpp` компилируется отдельно. Запустите программу из нужной папки `task-01` или `task-02` и введите длину вектора, затем его элементы. Команды сборки — в [общем README](../README.md#как-запустить).
